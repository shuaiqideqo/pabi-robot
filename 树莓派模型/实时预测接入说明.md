# 树莓派预测接入（11.18 超声波重拟合）

采集与 UART/APP 协议不变：子机 `CAP` → `main.py` 采 15s → 预测 → `R,cm=…,near=…,pd=…,st=…` → 子机/APP。

## 模型

- 目录：`E盘优化版_预测集成/predictor_11_18/`
- 内核：`model_v2.json` + `predict.py`
- 入口：`cap_prediction.py`（实验 `rawRegressionCm` → 现有 `distanceCm`）
  - 10–40 cm → 填 `cm`，`st=ok`
  - 0–10 cm → 也填实验 `cm`，`st=near`（CSV / `R` 行都有数值）
  - 大于 40 → `st=out`（不填 cm）
- 服务：`ae_uart_service.py` / 网页 `web_with_prediction.py` 均只走 11.18

依赖（树莓派上安装）：

```
pip3 install -r predictor_11_18/requirements.txt
# numpy、soundfile；系统还需 libsndfile
```

## 结果边界

- 推给 APP 的 cm 是实验估算（`deployment_ready=false`），不能当 ±8 cm 保证。
- 需要同名 `.pridb` + `.tradb`，2 MHz，完整窗约 200 000 点，`TR_mV≈0.00174`；`DataFormat` 0（Pi 原始）或 2（FLAC）均可。
- 预测只扫一遍波形库：选段后仅对选中窗算谐波特征，不再二次 `extract` 读盘。

## 预测结果落盘

每次 CAP 结束后写入（成功/失败都会记，避免旧版只有 error 看不出原因）：

- `prediction_log.csv`：追加表格（Excel 可开，含 `time/st/status/distanceCm/rawRegressionCm/reason/rLine/pridb`）
- `latest_prediction.json`：最近一次完整结果

查看：

```
tail -n 5 /home/admin/ae_project/prediction_log.csv
cat /home/admin/ae_project/latest_prediction.json
```

网页（`web_with_prediction.py`）有「历史测试结果」面板，读同一 CSV；接口 `/api/prediction/history`。
网页点「检测结果」仍不写入 CSV，只有 CAP 路径写入。
